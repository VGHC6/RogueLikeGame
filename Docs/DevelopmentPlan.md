# Development Plan — RogueLikeGame

## 目标

Unity 客户端开发，一年经验求职作品。展示架构能力、工程规范、Gameplay 设计理解。

---

## 第一阶段：收尾修复（预计 3-5 天）

### 1.1 Bug 修复
- [ ] 楼层推进后 ExitPoint 不生成（事件注册顺序问题 → `AllEnemiesDeadEvent`）
- [ ] 返回主菜单触发 `AllEnemiesDeadEvent` 导致越界崩溃（加 `_currentPhase` 判断）
- [ ] 存档 `_floorName` 改为动态：`$"第{state._currentFloor}层"`
- [ ] `SaveData` 增加 `_currentFloor` 字段，存/读档时写/读
- [ ] 读档复活死敌人：`SpawnFromRooms` 或加载流程中跳过 `IsDead` 的敌人
- [ ] `CleanupAll` 清理 ExitPoint（加 `ExitPoint` 标签）

### 1.2 内容补全
- [ ] 补齐 5 种道具的配置资产（Heal / AtkUp / DefUp / SpeedUp / MaxHpUp）：`Resources/Config/Items/`
- [ ] 玩家死亡动画 + 敌人死亡动画（FSM 加 Dead 状态）
- [ ] 加 2 种敌人变体（不同颜色 + 数值：近战弱/强/快速型，配置资产化）

### 1.3 工程规范
- [ ] 提交未提交的楼层推进代码
- [ ] 每个阶段结束时打 tag

---

## 第二阶段：地图重做（预计 5-7 天）

这是简历上第一眼的视觉冲击，也是战斗深度的基础。

### 2.1 房间类型
- [ ] `RoomType` 枚举：StartRoom / BattleRoom / BossRoom / TreasureRoom
- [ ] 地图生成时标记房间类型，BossRoom 放在远离起点的一端
- [ ] ExitPoint 只在 BossRoom 生成
- [ ] 地板颜色区分房间类型（Boss 红、起始绿、战斗灰）

### 2.2 障碍物系统
- [ ] `ObstacleConfig` ScriptableObject（碰撞体大小、血量、可破坏）
- [ ] 战斗房间随机生成障碍物（柱子、箱子），避免堵死
- [ ] 障碍物阻挡弹幕和移动（Collider2D）

### 2.3 地形变化
- [ ] 减速区域（特定 tile 上玩家/敌人移速降低）
- [ ] 陷阱区域（周期性伤害）

---

## 第三阶段：远程战斗（预计 5-7 天）

战斗深度核心，展示对 Gameplay 的设计能力。

### 3.1 弹幕系统
- [ ] `ProjectileData`（速度、方向、伤害、持续时间、穿透/消失）
- [ ] `Projectile` MonoBehaviour（Rigidbody2D 驱动移动，碰撞检测）
- [ ] 远程敌人类型（保持距离 + 发射弹幕）

### 3.2 远程武器
- [ ] 玩家拾取远程武器替换攻击方式（弓/法杖）
- [ ] 弹幕与障碍物碰撞（弹幕碰到障碍物消失）

---

## 第四阶段：Build 深度（预计 5-7 天）

让面试官看到你理解 Roguelike 的核心驱动。

### 4.1 楼层奖励
- [ ] Boss 房击杀后弹出三选一 Buff 面板
- [ ] Buff 类型：攻击力 +20%、移速 +15%、击杀回血、弹幕 +1、护盾 +1 等

### 4.2 武器替换
- [ ] 武器栏位（近战 / 远程）
- [ ] 宝箱房掉落不同武器
- [ ] 武器有基础属性差异（攻击力、范围、攻速）

### 4.3 小地图
- [ ] 探索过的房间在小地图上显示
- [ ] 当前房间高亮

---

## 第五阶段：表现力（预计 3-5 天）

锦上添花，录制展示效果好。

### 5.1 音效
- [ ] 攻击、受击、拾取、楼层切换的基础音效
- [ ] 背景音乐

### 5.2 视觉效果
- [ ] 伤害数字弹出
- [ ] 攻击轨迹/弹幕拖尾
- [ ] 道具拾取光效
- [ ] 屏幕过渡

### 5.3 UI 润色
- [ ] 暂停菜单用像素风字体
- [ ] HP 条动画过渡
- [ ] 设置面板（音量调节）
